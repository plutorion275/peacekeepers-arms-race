Capability Proxy

Military Technology Score — three specifications, carried in parallel

Rather than commit to one capability proxy, three independent specifications are constructed and carried through every RQ1 regression: MILEX-only (log-normalised mean spending), TIV-only (log-normalised cumulative arms-transfer value), and a PCA composite that lets the data set relative weighting across MILEX, TIV, and selected CoW CINC subcomponents. A finding that holds across all three is reported as robust; a finding that depends on one specification is flagged as specification-dependent, not general.

Panel Construction

Participation, not location

Conflict participation is built as a participant-level panel from UCDP's Dyadic Dataset — which country side was fighting — rather than a location-level panel derived from where fighting physically occurred. A location-based approach would attribute a conflict entirely to the country on whose soil it took place, systematically missing coalition members or external supporters — understating exactly the kind of externally projected, low-footprint engagement RQ1's instability channel is theorised to produce.

Final routing logic for a conflict's territory: intrastate/internationalised conflicts route to side A's (the defending government's) territory; bilateral interstate wars route to both parties; multi-state coalition invasions route to side B's territory, since UCDP encodes every coalition member in the same location code; extrasystemic conflicts route to the raw location field directly.

USA / GBR / AUS, Iraq War 2003 (multi-state coalition) — correctly flagged extraterritorial after the fix.
Russia, Syria intervention 2015 — correctly flagged extraterritorial.
India, Kargil 1999 — correctly flagged not extraterritorial (fighting on contested but own-claimed territory).
Net effect: total extraterritorial participant-years rose from 4,270 (naive text parse) to 4,720 (+450) under the corrected routing.
After-Action Report

Six pipeline defects, caught before they reached a regression

Each is logged here in full because catching it is itself part of the evidence for the reliability of the results that follow — not because the details matter to the substantive argument.

Incident 01 · Entity Resolution

A fuzzy country-name matcher initially resolved "Islamic State" to Iceland (ISO3 = ISL), inflating Iceland's apparent conflict count. Fixed with a dedicated resolver carrying per-dataset override rules.

Incident 02 · Source Query Defect

SIPRI's arms-transfer portal was found, via manual audit against SIPRI's own published totals, to silently return export totals instead of import totals regardless of the UI selection — which would have inverted the capability proxy for every exporting country if left uncaught.

Incident 03 · Coalition Undercounting

UCDP's dyadic data fold multi-state coalitions into a single location code, systematically undercounting coalition members as extraterritorial participants — caught via a spot-check on the 2003 Iraq War, exactly the outcome RQ1 tests.

Incident 04 · Successor-State Aggregation

Historical-state variables (USSR, Yugoslavia, Czechoslovakia) were initially aggregated across successor states by arithmetic mean instead of sum — silently halving expenditure and population figures for any country touched by a split.

Incident 05 · Zero vs. Missing

The TIV series used a literal zero for both "no data reported" and "genuinely zero imports," biasing roughly 5,400 country-years toward the bottom of the capability scale until the two were disambiguated.

Incident 06 · Stale Robustness Flag

A downstream RQ2 robustness flag was computed in memory after its results table had already been written to disk — the saved file never reflected it. Caught only by a later notebook's attempt to re-read the saved file, which is why every result below is cross-checked against actual saved output, not trusted from memory.

Key Methodological Choices

Four decisions the results depend on

Capability Proxy

PCA-composite as primary spec

The primary specification (mts_pca_3feat) drops CoW's milper to extend coverage to 2024, since CINC itself truncates at 2016.

RQ2 Null Model

Circular-shift replaces shuffle

A circular-shift null is used in place of the conventional shuffle null, since shuffling destroys the negative serial structure inherent to arms-transfer time series — see the full case file on RQ2.

Panel Balance

Balanced grid, NaN-tolerant estimators

A balanced (iso3 × year) grid is used with NaN-tolerant estimators, rather than truncating the sample to the shortest-covered source.

Cluster Stability

0.50 threshold, not 0.75

Recalibrated to reflect the theoretical stability ceiling for bootstrap-with-replacement resampling at n=157 (Ben-Hur et al. 2002), not the 0.75 convention built for cross-validation resampling.
