Reproduce It

Run the pipeline yourself

Clone the repo, create a virtual environment, install requirements, follow data/README.md to download raw sources (SIPRI, UCDP, World Bank, V-Dem, CoW) into data/raw/, then run notebooks 00→14 in numeric order. Each notebook consumes the previous notebook's Parquet checkpoint and is independently re-runnable.

git clone github.com/plutorion275/peacekeepers-arms-race
python -m venv .venv && pip install -r requirements.txt
jupyter nbconvert --to notebook --execute notebooks/*.ipynb

AI-Use Disclosure

Disclosed in full, not minimized

Every AI-assisted output — code, statistical claim, and manuscript text alike — was directed, reviewed, and checked against the underlying data by the author before inclusion. Every numerical claim in the manuscript traces to a specific saved result rather than to AI-generated text taken on faith. The research questions, methodological judgment calls, interpretation of results, and conclusions are the author's own.

Reproducibility Notes

Built to be checked, not just trusted

Parquet, Not Pickle

Cross-version safe handoffs

Inter-notebook handoffs use Parquet, not Pickle, to avoid breakage across pandas versions.

Guard Cells

PASS/FAIL sanity checks

Each notebook contains PASS/FAIL sanity-check cells and, where relevant, a regression guard against frozen reference values.

Custom DH Test

60+ min → 1–2 min

A numpy-based Dumitrescu-Hurlin implementation is used where no maintained Python package exists, cutting runtime dramatically versus a naive approach.
